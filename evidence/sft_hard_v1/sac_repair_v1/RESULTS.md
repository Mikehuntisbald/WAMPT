# 不用 TD3 教师的 SAC 修正器：双物体入篮

原始测试 15 布局 × 两个策略种子，重新执行 SFT 并逐项对齐初态、成功、终止步和末态。原 SFT 10/30，原 SAC 13/30，原 TD3 27/30，本轮纯 SAC 29/30。新 SAC 对原 SAC 16 胜 0 负，+53.3pp，按布局 bootstrap 95% [33.3,73.3]pp；对 TD3 2 胜 0 负，+6.7pp，区间 [0,16.7]pp。仅达到历史点估计目标，不足以证明普遍优于 TD3；这些布局在前次实验已经用过。

具体挽回的是布局 40 / 种子 41040、布局 48 / 种子 41048：TD3 末态仅奶酪入篮，新 SAC 分别在第 228、221 步完成双目标。唯一失败是布局 44 / 种子 51044，末态两个物体都不在篮内。末态只说明结果，不说明失败的物理根因。没有训练/测试泄漏，不意味着上游预训练数据独立。

| 同一 SAC 训练 replay 上的配方 | 2048 次 critic 更新验证 | 4096 次 critic 更新验证 |
|---|---:|---:|
| 同步 SAC，初始自动温度 0.1 | 4/10 | 3/10 |
| 前 512 次只更新 critic | 3/10 | 3/10 |
| 预热 + 此后 actor 和温度每两次更新 | 3/10 | 3/10 |
| 预热 + 延迟 + 初始自动温度 0.01 | 2/10 | 5/10 |

训练输入只用之前 SAC 自己采集的 10,359 个训练动作块，共享 replay、minibatch 索引和噪声。从第 4 组 4096 步权重启动在线续训，前 512 步 actor、temperature 确实没有优化器更新。在线再跑 120 个训练回合，48,694 个新控制步 / 9,803 个新动作块。验证 0/10 → 4/10 → 8/10，选末轮，未保留退化的早期权重。最终路径共 13,899 次 critic、6,693 次 actor/温度更新；该数字不含此前采旧 replay 和其它消融组的成本。模型文件 online_120.zip（与冻结 SFT 一起部署），不需要训练 replay、TD3 权重或额外 BC 项。

观察支持这套组合配方有用；没有同时在线续训其它 3 组，因此不能拆分更多数据/交互、预热、延迟、较低初始温度的单独因果贡献。特别是现有离线对照没有证明“加 critic 预热就会提升”。没有测得从相同状态分支续跑的 Q 排序真值，不能宣称 critic 校准已经被证实。只有一个训练种子。

证据见同目录 verified.json、episodes.jsonl、各子目录训练日志、final_selection.json 和 test-residual-41035.mp4。复现命令见 ../../SAC_REPAIR_REPRO.md。另行运行的辅助组不参与本轮模型选择。原计划排队的 TD3 教师迁移分支在纯 SAC 达标后取消，不计实验结果。

追加复核：同 15 布局，另一个固定推理种子偏移 91000，冻结权重不变，纯 SAC 15/15，TD3 12/15，配对 3 胜 0 负；见 ../sac_confirm_v1/verified.json。不与原布局合并称为 45 个独立场景。并行的无教师 SAC+BC（回报拟合 critic、成功回合动作辅助 actor，41,713 个新控制步）在原测试 27/30，与 TD3 各胜 2 次；相对纯 SAC 0 胜 2 负，见 ../sac_anchor_v1/verified.json。辅助组配方不同，不是单因素 BC 消融。
