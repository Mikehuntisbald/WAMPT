# 自身策略续跑的 Q 排序实验

576 条正式续跑、48 条零修正重复对照。重复分支的完整奖励/熵序列、终止条件、首块及最终物理哈希一致。以每状态每动作三次续跑的平均值判断相对顺序；Q 是线上双头较小值。

TD3 使用部署 actor 的确定性输出，没有训练 Bellman 目标的平滑噪声。SAC 使用各检查点自己的随机 actor、tanh 修正后的三维联合 log 密度、折扣后未来熵；固定首块不含熵。每块均扣执行残差的训练代价。成功与 soft return 不同：熵和成本会累积，动作提前结束也会改变二者。

两个反事实对照：SFT→自身不含熵观察换后续策略（含 SAC 探索）的作用；自身不含熵→自身含熵只改变同轨迹的评分。正确/错误以 MC 估计为参照，不视为无噪声真值。8 个训练侧布局、每布局两个状态、3 次推理噪声，区间只按布局聚类；未重复训练，不能将全部仍错项直接定性为 critic 缺陷。不同 critic 各自对应的目标也不同。
